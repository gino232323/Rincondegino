# El rincón de Gino

Sitio para gamers y creadores de Hugo «Gino» Hermosillo.

Visita **[El rincón de Gino](https://gino232323.github.io/Rincondegino/)** para conocer y abrir estos proyectos en tu navegador:

- **Play Night: Ánimas de México:** juego de granja y supervivencia en pixel art inspirado en México.
- **Panzer vs Tiger:** juego de combate de tanques.
- **Cortador de Sprites:** herramienta para separar hojas de sprites y descargar sus frames en PNG.
